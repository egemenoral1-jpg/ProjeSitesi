# Proje Kasetleri

Projelerimi bir VHS kaset rafı olarak sunan küçük site. Bir kasete tıklayınca Mordecai kaseti raftan alır,
televizyona takar ve projenin açıklaması ekranda belirir. Başka bir kaset seçilirse eskisi önce raftaki yerine geri konur.

Düz HTML/CSS/JS, build gerekmez:

```bash
python -m http.server 5199
```

Projeleri değiştirmek için `js/main.js` içindeki `PROJECTS` listesini düzenleyin.
